# 原型说明与验证

更新日期：2026-09-10。打开 [交互原型](prototype.html) 即可演示。本轮调整用于评审体验方案，不代表正式应用已经实现全部交互。

## 本轮调整

- 将错过计划、已逾期统一到「待恢复」，保留原因标识和分类数量，逾期事项优先展示，可完成、跳过和重新安排。
- 今天聚焦当天待办，实际在今天完成的事项单独折叠。仅标题新增提供明确的去向提示和查看入口。
- 筛选支持真实状态选择、已选条件和清除；中文搜索在输入法组合结束后更新，避免中途重绘打断输入。
- 改期保留具体时间，校验计划与截止顺序；重复事项区分本次操作和未来安排。
- 日历提供日、周、月和日程视图，明确区分计划与截止。日视图按时间分组排序，不用卡片高度暗示持续时长。
- 历史统一展示普通与重复事项，完成、跳过可分别查看。目标支持关联新增，进度按关联普通任务的完成比例计算。
- 手机底部提供今天、日历、收件箱、待恢复、更多五个入口，清单及低频页面收纳到更多。
- 表单使用原生对话框，支持关闭、Esc 和焦点返回；次要字段折叠展示。

重复任务只演示已有示例的本次操作和后续安排，不模拟完整规则编辑或无限生成。备份、恢复及系列管理按钮标注为流程说明；设置不请求通知权限、不执行真实数据操作。回顾展示当天统计，完整周期切换不在本轮演示范围。

## 2026-09-22 子任务清单（仅原型）

## 2026-09-22 子任务正式应用接入

普通任务新增与详情接入子任务清单，支持 Enter 连续添加、名称编辑、完成勾选、删除、保存与取消。任务列表展示进度；历史子项只读。子项没有计划、截止或提醒，不独立进入日历、恢复或统计。全部子项完成不改变主任务状态，主任务完成、跳过、撤销或改期保留子项。重复事项支持情况见下节。
