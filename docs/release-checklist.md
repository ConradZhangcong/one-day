# One Day PWA 发布检查清单

本文档记录 PWA 发布加固的自动化证据，以及每次正式发布前仍需在真实设备上执行的人工门禁。未勾选项目不得描述为已验证。

## 自动化门禁

在仓库根目录执行：

```bash
pnpm format:check
pnpm lint
pnpm typecheck
pnpm test:run
pnpm test:pwa
pnpm test:e2e
pnpm test:performance
pnpm build
```

`test:pwa` 会重新构建生产产物，并验证 manifest、普通与 maskable 图标尺寸、Apple touch icon、Service Worker、Workbox 运行时和导航外壳预缓存。验证器包含字段篡改与资产缺失的反向测试。

`test:e2e` 的共享核心流程覆盖：

- Desktop Chrome、Desktop Firefox、Desktop Safari（WebKit）、Pixel 7 等效视口和 iPhone 15 等效视口。
- 通过可见界面创建并安排任务，在“今天”和“日历”中确认一致性，完成后在“已完成”中确认结果。
- 深层路由刷新、浏览器后退/前进和 404 错误边界。
- 键盘快速新增与焦点可见性、200% 根字号、页面级水平溢出、浅色与深色主题。
- Chromium 中的 Service Worker 控制、断网后关闭并重开深层路由、IndexedDB 数据保留、离线新增，以及恢复联网后无丢失和重复。

非 Chromium 项目显式阻止 Service Worker，以隔离 Playwright 引擎能力差异；核心业务断言保持一致。Service Worker 生命周期检查只在 Chromium 中执行。

## 性能证据

基准使用确定性夹具、一次预热和五次测量的中位数。当前开发环境为 Node.js v24.18.0：

| 场景           |                          数据规模 |       预算 | 当前中位数 |
| -------------- | --------------------------------: | ---------: | ---------: |
| 待办快照       | 2,000 个普通任务 + 200 个重复系列 | ≤ 1,000 ms |     494 ms |
| 14 天日历查询  |                              同上 | ≤ 1,000 ms |     252 ms |
| 366 天重复投影 |                    200 个重复系列 | ≤ 2,000 ms |     538 ms |
| 移动首屏可交互 |                  Pixel 7 等效视口 | ≤ 3,000 ms |     341 ms |

不同机器上的绝对耗时会变化；发布门禁以测试中的预算断言为准，并保留原始输出用于对比回归。

## Android 真机发布门禁

- [ ] 使用目标最低 Android 版本与当前 Chrome 稳定版打开生产 HTTPS 地址。
- [ ] 安装提示或浏览器菜单可以安装应用，名称、普通图标与启动画面显示正确。
- [ ] 从主屏幕启动后保持 standalone 显示，返回键、底部导航和深层路由行为正确。
- [ ] 创建任务并确认“今天”与“日历”一致；完全关闭应用后重新打开仍能读取数据。
- [ ] 联网打开一次后断网，完全关闭并从主屏幕重启；外壳和深层路由可用，离线新增在恢复联网后无丢失或重复。
- [ ] 仅在用户主动操作时请求通知权限；允许、拒绝和稍后提醒路径均可恢复。
- [ ] 导出 JSON 备份，删除或更改一条测试数据，再导入并确认预检摘要、整库恢复和失败回滚。
- [ ] 部署新版本后出现升级提示；关闭提示不会立即更新，主动确认后完成升级且数据保留。

## iOS / iPadOS 真机发布门禁

- [ ] 使用目标最低系统版本与当前 Safari 打开生产 HTTPS 地址。
- [ ] 通过“添加到主屏幕”安装，名称、Apple touch icon 和启动后的 standalone 外观正确。
- [ ] 从主屏幕启动，检查安全区、键盘、对话框、底部导航和旋转后的布局。
- [ ] 创建任务并确认“今天”与“日历”一致；完全关闭应用后重新打开仍能读取数据。
- [ ] 联网打开一次后断网，完全关闭并从主屏幕重启；外壳和深层路由可用，离线新增在恢复联网后无丢失或重复。
- [ ] 在系统与浏览器支持时，仅通过用户主动操作请求通知权限；不支持或拒绝时应用仍可正常使用。
- [ ] 通过系统文件选择器导出并重新导入 JSON 备份，确认预检摘要、整库恢复和失败回滚。
- [ ] 部署新版本后验证升级提示、主动更新和数据保留。

## 已知边界

- 当前没有账号、云同步或服务端 Web Push。
- 页面进入受限后台、设备挂起或浏览器/PWA 完全关闭后，提醒不能保证准时送达。
- Android 与 iOS 真机清单是每次发布前的人工门禁；本仓库自动化结果不能替代真机结论。
- Vite 当前会报告单个压缩前 chunk 超过 500 kB 的警告；移动首屏预算已通过，但后续仍应持续评估路由级拆包。
