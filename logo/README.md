# Concentric Ring Logo Assets

这套 Logo 以“空心圆”为核心，由严格对齐的多层同心圆组成。外层细线负责建立精密边界，主圆环承担品牌识别，内层圆环增加空间感和金属层次。所有独立 Logo 均为透明背景 SVG，可无损缩放。

## 文件说明

| 文件                                     | 中文名称     | 用途                                                             |
| ---------------------------------------- | ------------ | ---------------------------------------------------------------- |
| `concentric-ring-master-metal.svg`       | 标准金属版   | 核心母版。适合官网、产品界面、名片及正式品牌物料。               |
| `concentric-ring-preview-light-dark.svg` | 明暗背景预览 | 展示标准版在浅色和深色背景上的效果，不作为直接投放的 Logo 文件。 |
| `concentric-ring-color-guide.svg`        | 彩色版本总览 | 用于内部选色、提案和品牌沟通，不作为直接投放的 Logo 文件。       |
| `concentric-ring-cobalt.svg`             | 钴蓝版       | 适合科技、数字产品、金融与强调可信度的场景。                     |
| `concentric-ring-emerald.svg`            | 翡翠绿版     | 适合生活方式、可持续、健康与强调成长感的场景。                   |
| `concentric-ring-amethyst.svg`           | 紫晶版       | 适合创意、文化、高端服务与具有未来感的数字场景。                 |
| `concentric-ring-vermilion.svg`          | 赤金版       | 适合活动、节庆、会员体系与需要热度和仪式感的场景。               |

## 推荐使用层级

1. 默认优先使用标准金属版，保持品牌识别稳定。
2. 钴蓝版可作为数字产品的首选主题色版本。
3. 翡翠绿、紫晶和赤金建议用于栏目、活动或限定主题，不建议同时出现在同一画面中。
4. Logo 周围建议至少保留相当于最内层与主圆环之间距离两倍的安全空间。
5. 小尺寸使用时，建议最小显示宽度为 32 px；低于 32 px 时可移除最外层与最内层的细线。

## 编辑说明

- 画布尺寸：`512 × 512`
- 圆心坐标：`256, 256`
- 独立 Logo：透明背景
- 文件格式：SVG 1.1 兼容矢量结构
- 若需制作纯色印刷版，可将全部描边统一替换为单一专色，并移除渐变高光描边。
