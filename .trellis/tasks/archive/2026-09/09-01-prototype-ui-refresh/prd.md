# 按原型重构应用界面

## Goal

让当前 One Day React 应用的页面结构、视觉层级与交互入口贴合 `docs/prototype.html`，同时复用现有本地优先待办、恢复、回顾和设置能力，不破坏已实现的数据行为。

## Background

- 交互与视觉来源为 `docs/prototype.html`，采用浅色、中性灰、紧凑侧栏、卡片式内容区和移动端底部导航。
- 当前应用使用 React 19、React Router、Ant Design 6、IndexedDB/Dexie；已有待办、清单、恢复、回顾、设置和提醒功能。
- 当前 `/calendar/:view` 仍是占位页；原型则展示议程、日、周、月与长期目标等完整界面。
- 原型中的“长期目标”和部分日历内容是演示数据，当前领域模型和服务层尚无对应完整能力。
- 用户要求将现有 Ant Design 组件库完整替换为 shadcn/ui；项目当前尚未安装 shadcn/Tailwind，现有表单、抽屉、消息与弹窗需要迁移。
- 历史原型决策已确认：年度热力图改为“长期目标”；任务创建/编辑时可选关联一个长期目标；目标只提供方向，不自动排程。
- 用户确认本次需要把日历与长期目标做成使用真实本地数据的功能，而非仅保留占位界面。
- 用户确认长期目标进度由关联普通任务的完成状态自动计算。
- 用户确认完整重复任务管理应作为后续独立任务；本任务只读取数据库中已有重复系列和实例，不提供规则编辑或生命周期命令。

## Task Map

1. `09-01-prototype-ui-shell`：应用外壳、导航及现有页面视觉重构。
2. `09-01-calendar-views`：议程、日、周、月真实数据视图与任务下钻。
3. `09-01-long-term-goals`：长期目标持久化、自动进度和普通任务关联。

三个子任务共享本 PRD 的原型和集成验收要求；因 shadcn 基础设施是所有新页面的前置条件，按 UI 外壳与组件迁移 → 长期目标 → 日历的顺序实施，最后在父任务范围做集成检查。

## Requirements

1. 应用外壳、侧栏/移动导航、品牌标识、页面留白、字体、色彩、边框、卡片、按钮和状态标签应与原型保持一致的设计语言。
2. 已实现的待办、清单、恢复、回顾、设置、提醒和任务详情行为必须继续使用真实本地数据和现有服务，不得替换为静态演示数据。
3. 桌面端需支持可收起侧栏；移动端需提供不遮挡核心内容的紧凑导航。
4. 快速新增、筛选、任务状态操作、详情编辑、清单管理与反馈消息应在新布局中可用。
5. 响应式布局需覆盖桌面与手机宽度，且保留键盘焦点、语义标签和非纯颜色状态表达。
6. 使用 shadcn/ui + Tailwind CSS 重建通用 UI 原语，并移除产品代码对 `antd` 与 `@ant-design/icons` 的依赖；图标统一使用 Lucide。
7. 日历需提供议程、日、周、月四种真实数据视图，并从同一任务事实来源展示全天计划、精确计划和仅截止事项；任务可从日历打开详情并执行现有状态操作。
8. 长期目标需支持创建、编辑、状态管理和与普通任务的可选关联；关联不改变任务独立存在、排程或状态规则。
9. 长期目标进度自动计算为已完成关联任务数除以全部关联任务数；没有关联任务时为 0%。任务新增关联、清除关联、完成、撤销完成或删除后，目标进度随真实数据更新。
10. 目标状态采用“计划中、进行中、已完成、已归档”；已归档目标不出现在新关联选择中，但历史任务关联仍可辨认。
11. 数据库中已有重复实例可出现在日历中，但在完整重复管理任务交付前保持只读并明确标注。

## Acceptance Criteria

- [ ] 桌面首页的品牌、侧栏、标题区、导航选中态、卡片与任务列表在布局和视觉上明显匹配原型。
- [ ] 侧栏可收起并可重新展开；移动宽度下核心导航和任务操作可用且无水平溢出。
- [ ] 用户可新增、搜索/筛选、打开、编辑、完成、跳过及删除任务，原有测试行为保持通过。
- [ ] 恢复、回顾和设置页统一采用原型设计语言，功能无回退。
- [ ] 议程、日、周、月视图基于真实本地任务数据展示，并可切换日期范围、返回今天和打开任务详情。
- [ ] 用户可创建和编辑长期目标，并在新增/编辑任务时选择或清除目标关联；刷新应用后数据仍存在。
- [ ] 所有新增交互具有可访问名称与可见焦点，状态不只依赖颜色。
- [ ] `pnpm lint`、`pnpm typecheck`、相关单元测试及生产构建通过。
- [ ] 三个子任务分别通过自身验收，且目标关联、任务操作和日历刷新在同一真实数据源下保持一致。
- [ ] `src/` 与测试代码不再导入 `antd` 或 `@ant-design/icons`，迁移完成后从 `package.json` 移除这两个依赖。

## Out of Scope

- 账号、云同步或服务端能力。
- 重写领域模型、数据迁移或改变现有任务语义。
- 完整重复任务创建、规则编辑、实例推进、仅本次改期及暂停/恢复/停止；该能力另立独立任务。
- 年度热力图；原型已明确将该入口替换为长期目标。
