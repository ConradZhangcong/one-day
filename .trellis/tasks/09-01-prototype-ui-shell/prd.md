# 重构应用外壳与现有页面视觉

## Goal

按照 `docs/prototype.html` 重构应用外壳、导航、待办、恢复、回顾和设置页，使现有真实功能获得一致、清晰、响应式的产品界面。

## Background

- 原型采用 shadcn 默认中性色、黑色主按钮、紧凑侧栏、较大的统一图标、卡片和移动端导航。
- 项目当前使用 Ant Design 6；用户要求完整迁移到 shadcn/ui，所有现有表单、抽屉、消息、弹窗、加载、空状态和图标需保持行为后完成替换。
- 标准品牌资源为 `logo/concentric-ring-master-metal.svg`。

## Requirements

1. 桌面端使用 256px 左侧栏、品牌区、全局快速新增、分组导航、自定义清单和本地优先说明；侧栏可收起并保持可恢复入口。
2. 导航展示今天、即将到来、收件箱、错过计划、已逾期、已完成、日历、长期目标、回顾、设置及自定义清单；选中态、图标与数量层级贴合原型。
3. 待办页重排标题区、快速新增、筛选和任务卡，但保留真实新增、编辑、完成、跳过、撤销、删除、清单管理和提醒行为。
4. 恢复、回顾和设置页统一使用原型卡片、标签、按钮、说明和内容密度。
5. 任务详情抽屉及主要弹窗跟随同一主题，并在手机宽度可完整操作。
6. 移动端使用紧凑底部导航或等效模式，不能遮挡内容；低频入口仍可到达。
7. 保留语义化结构、可见焦点、键盘操作、文字缩放和非纯颜色状态表达。
8. 在现有 Vite 项目中配置 Tailwind CSS v4 与 shadcn/ui 默认 Base UI/neutral 主题；通用组件源码归入 `src/components/ui/`，图标使用 Lucide。
9. 替换所有 `antd`、`@ant-design/icons` import 和 `App.useApp`/ConfigProvider 依赖；消息使用 shadcn 推荐的 toast/sonner 能力，确认流程使用 AlertDialog，详情使用 Sheet/Drawer。
10. 迁移完成并验证零引用后，从 `package.json` 移除 Ant Design 及其图标依赖。

## Acceptance Criteria

- [ ] 桌面布局在品牌、侧栏、导航、标题、卡片、按钮、状态标签和留白上明显匹配原型。
- [ ] 侧栏可收起/展开；刷新后无需持久化收起状态。
- [ ] 手机宽度下无页面级水平溢出，主要导航、新增、筛选、任务操作和详情可用。
- [ ] 现有待办、恢复、回顾、设置、清单和提醒交互无功能回退。
- [ ] 使用标准 Logo，主要图标尺寸和对齐与原型一致。
- [ ] 组件测试、可访问性相关断言、lint、typecheck 和 build 通过。
- [ ] 所有原 Ant Design 使用点已迁移，`src/` 与测试中零旧库 import，package 依赖已清理。
- [ ] shadcn 组件保留在仓库中，可由项目直接维护；不在业务组件复制通用 primitive 实现。

## Out of Scope

- 改写领域/持久化逻辑、主题自定义器和用户可配置导航。
