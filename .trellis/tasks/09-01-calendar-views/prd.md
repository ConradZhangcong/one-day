# 实现真实数据日历视图

## Goal

让用户通过议程、日、周、月四种真实数据视图理解计划、截止和每日负载，并从日历进入现有任务处理流程。

## Background

- 当前 `/calendar/:view` 为占位页，项目已安装 FullCalendar React 7。
- 普通任务已区分计划与截止；数据库也有重复系列/实例模型，但完整重复 projector 和管理用例尚未实现。
- 本任务不恢复原 PRD 的年度热力图，原型已用长期目标替代该入口。

## Requirements

1. 提供 `/calendar/agenda|day|week|month` 四种视图，URL 保存视图和锚点日期；支持前一范围、后一范围和返回今天。
2. 四种视图消费同一个 typed calendar query，不得各自解释原始任务或重复记录。
3. 全天计划进入全天计划区；精确计划进入时间轴；只有截止的任务显示截止标记，不伪造成计划时间块；同时有计划与截止时在计划位置展示并附截止信息。
4. 议程按本地日期连续列出恢复、当前和未来事项；日视图含全天计划和时间点；周视图周一开周并显示每日待处理计划负载；月视图限制标签数量并用 `+N` 下钻。
5. 普通任务可从任一视图打开详情，并使用现有完成、跳过和重新安排能力；操作后所有视图实时更新。
6. 数据库中已有重复实例按系列模板和实例 override 投影；在完整重复管理任务交付前保持只读并明确标注。
7. 筛选至少支持清单、优先级和任务状态，并通过 URL 保留。
8. 所有日期计算使用应用配置的 IANA 时区；全天日期不得经 UTC 转换漂移。
9. 日历页头、标签、筛选、任务详情、空状态和反馈使用项目本地 shadcn/ui primitive；FullCalendar 只作为日历布局引擎，不作为通用组件库。

## Acceptance Criteria

- [ ] 议程、日、周、月在相同日期范围和筛选条件下展示一致的真实事项集合。
- [ ] 全天计划、精确计划、仅截止及同时有计划/截止的普通任务位于正确的视觉区域。
- [ ] 周视图以周一开始，负载等于当天待处理计划任务/当前重复实例数量。
- [ ] 月视图溢出显示 `+N`，点击日期可下钻到日视图。
- [ ] 普通任务可打开详情、完成、跳过和重新安排，保存后视图自动刷新。
- [ ] 现有重复实例正确显示为只读并具有明确标签；无完整规则 projector 时不生成数据库之外的未来实例。
- [ ] 时区、投影、视图组件和主要交互测试通过。
- [ ] 日历功能产品代码零 `antd`/`@ant-design/icons` import。

## Out of Scope

- 年度热力图、拖拽改期、持续时间/时间块、冲突检测和容量规划。
- 重复规则展开、创建/编辑、实例推进、单次改期及暂停/恢复/停止；另立独立任务。
